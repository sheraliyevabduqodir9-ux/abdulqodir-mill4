ABDULQODIR MILL — sayt fayllari

1) ZIP faylni oching.
2) Ichidagi index.html, css papkasi va js papkasini bitta GitHub repository asosiy papkasiga joylang.
3) Eski index.html, css/style.css va js/main.js fayllari bo‘lsa, yangilari bilan almashtiring.
4) GitHub repository → Settings → Pages bo‘limida:
   - Deploy from a branch
   - Branch: main
   - Folder: / (root)
   - Save
5) Sayt manzilini ochib tekshiring. Brauzerda Ctrl + F5 bosing.
